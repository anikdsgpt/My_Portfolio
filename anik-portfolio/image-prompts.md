# Portfolio AI Image Prompt Plan

Use these prompts to generate project visuals and save them exactly with the given filenames in the images folder.

## Global generation settings
- Aspect ratio: 16:9
- Recommended size: 1600x900 (or larger)
- Style: cinematic professional, tech illustration, clean UI elements, high contrast
- No text, no logos, no watermarks, no brand names
